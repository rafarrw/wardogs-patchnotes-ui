# Contributing

Thanks for helping out. Fixes and additions are welcome.

## Reporting a wrong number

Open an issue and say which item it is, what the page shows, and what it should show. Include a link to where the correct number comes from (patch notes, dev post, screenshot).

## Sending a pull request

1. Fork the repo and make your change in `index.html`. All the data lives in the arrays near the top of the `<script>` block.
2. Open the page in a browser and check that your change shows up correctly, in both English and Portuguese if you touched any text.
3. Open the pull request and explain what you changed and where the numbers come from.

Every pull request is reviewed by hand before it gets merged. Nothing is merged automatically.

## A few rules

- Only numbers that come from an official source.
- Keep it to one topic per pull request. Smaller is easier to review.
- If you add text, add it to both languages (`pt` and `en` in the `I18N` object).
